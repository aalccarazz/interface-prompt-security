# SecNudge sample project

A disposable workspace for testing the SecNudge Claude Code submission nudge.
No installation or existing application is required.

1. Use this folder from the repository checkout, or copy it to a separate local workspace.
2. In SecNudge, click Enable Claude Code nudge and select this folder.
3. Click Check setup and select this same folder.
4. Open this folder in VS Code and start a fresh Claude Code session here.
5. Submit the exact prompt in TASK.md. The demo hook should pause it.
6. Add the suggested requirement and resubmit manually if you want Claude to continue.

The hook uses a hand-written exact-match example. Other prompts passing does
not establish security. Hook setup is not enabled automatically by this download.
Claude Code may retain submitted prompts in its own session history.

When done, use Disable nudge in SecNudge and select this folder.
